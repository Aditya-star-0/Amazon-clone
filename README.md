 # Amazon Front Page Clone

This project is a **static front page clone of Amazon**, built using **HTML and CSS**.  
It replicates the look and feel of Amazon’s homepage, including the navigation bar, search bar, product sections, and footer.

## 🚀 Features
- Responsive navigation bar with logo, search, and cart icons
- Dropdown menus for categories and languages
- Hero section with product boxes
- Footer with multiple informational links
- Styled using external CSS and Font Awesome icons

## 🛠️ Technologies Used
- HTML5
- CSS3
- [Font Awesome](https://fontawesome.com/) for icons
